    Set up the iPhone share button
    1. Open the Shortcuts app, tap +, name it Rack it.
    2. Tap the ⓘ info button, turn on Show in Share Sheet, and set it to receive URLs and Text.
    3. Add the action Copy to Clipboard (input: Shortcut Input).
    4. Add the action Open URLs with this page's link: https://claude.ai/artifact/Dgh14Ha89eTYWcSVVRApe8
    5. Now in Instagram or YouTube: Share → Rack it. This page opens; tap the link box and Paste.

    Reminder: in Shortcuts, go to Automation → Time of Day, pick your workout days, and add Open URLs with this page's link.
